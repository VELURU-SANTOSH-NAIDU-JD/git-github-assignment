GIT COMMANDS USED IN THE ASSIGNMENT

1. git init -b main
   Initializes a new Git repository with main as the default branch.
2. git status
   Displays the current state of the working directory and staging area.
3. git add .
   Adds all untracked and modified files to the staging area.
4. git add index.html
   Adds the specified HTML file to the staging area.
5. git commit -m "Initial commit: Add HTML files"
   Saves the staged changes as a commit with a descriptive message.
6. git commit -m "Update homepage content"
   Creates a commit after modifying the homepage.
7. git branch feature
   Creates a new branch named feature.
8. git branch
   Lists all local branches and identifies the current branch.
9. git switch feature
   Switches the working directory to the feature branch.
10. git add about.html
    Stages the changes made to about.html.
11. git commit -m "Add new content in feature branch"
    Commits the changes made in the feature branch.
12. git switch main
    Switches back to the main branch.
13. git merge feature
    Merges the feature branch into the main branch.
14. git log --oneline --graph --all
    Displays the commit history in a compact graphical format.
15. git status --ignored
    Displays the working tree status, including ignored files.
16. git add .gitignore
    Stages the .gitignore file.
17. git commit -m "Add gitignore configuration"
    Commits the Git ignore configuration.
18. git add contact.html
    Adds the contact page to the staging area.
19. git commit -m "Add contact page"
    Creates an additional commit containing the contact page.
20. git revert HEAD
    Creates a new commit that reverses the most recent commit.
21. git remote add origin <repository-url>
    Connects the local repository to the remote GitHub repository.
22. git remote -v
    Displays the configured remote repository URLs.
23. git add git_commands.txt
    Adds the command documentation file to the staging area.
24. git commit -m "Add Git command documentation"
    Commits the Git command documentation file.
25. git push -u origin main
    Pushes the local main branch to GitHub and sets its upstream branch.
26. git push -u origin feature
    Pushes the feature branch to GitHub and sets its upstream branch.
